Primary CTA and secondary actions with the NOD doodle border; hover on primary flips to charcoal with a yellow offset shadow.

```jsx
<Button icon="login">Google로 시작하기</Button>
<Button variant="secondary">더 보기</Button>
<Button variant="text">모든 확장 프로그램 연결 해제</Button>
```
Variants: primary | secondary | mint | plain | text. Props: size sm/md/lg, icon, loading, disabled, href. Min height 44px (md).
