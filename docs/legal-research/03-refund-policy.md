> **주의**: 본 문서는 법률 정보 제공 목적이며, 정식 법률 자문을 대체하지 않습니다.

## 1. 한국 법률 기준 환불 관련 규정

### 1.1 전자상거래법 제17조 (청약철회)

**근거법령:** 전자상거래 등에서의 소비자보호에 관한 법률 (시행 2025.2.14, 법률 제20302호)

**제17조 제1항 -- 기본 청약철회권 (7일)**

소비자는 계약 내용에 관한 서면을 받은 날 또는 재화/용역의 공급이 시작된 날부터 **7일 이내**에 청약철회가 가능합니다.

- 서면을 받은 날부터 7일
- 서면 수령보다 공급이 늦은 경우, 공급받은 날부터 7일
- 서면을 받지 못한 경우: 주소를 안 날 또는 알 수 있었던 날부터 30일

### 1.2 전자상거래법 제17조 제2항 -- 청약철회 제한 사유

| 호 | 제한 사유 | NOD 관련성 |
|---|---|---|
| 제1호 | 소비자 귀책 사유로 멸실/훼손 | 해당 없음 |
| 제2호 | 사용/소비로 가치 현저 감소 | 부분 해당 (AI 크레딧 소진) |
| 제3호 | 시간 경과로 재판매 곤란 | 해당 없음 |
| 제4호 | 복제 가능 상품 포장 훼손 | 해당 없음 |
| **제5호** | **용역 또는 디지털콘텐츠 제공 개시** | **핵심 해당** |

**제17조 제2항 제5호 단서 -- "가분적 디지털콘텐츠" 특례 (매우 중요)**

> "가분적 용역 또는 가분적 디지털콘텐츠로 구성된 계약의 경우에는 제공이 개시되지 아니한 부분에 대하여는 그러하지 아니하다."

**NOD 적용**: SaaS 구독 서비스는 월/연 단위로 제공되는 **"가분적 용역"**에 해당. 따라서:
- 이미 제공된 기간은 환불 제한 가능
- **아직 제공되지 않은 잔여 기간은 청약철회/환불 가능**
- 현재 "14일 이후 환불 불가" 정책이 법적으로 문제될 소지 있음

### 1.3 전자상거래법 제17조 제6항 -- 사업자 의무

디지털콘텐츠에 대해 청약철회가 불가능한 경우:
1. 청약철회 불가능 사실을 **명확히 표시**
2. **시험 사용 상품(trial)** 제공 등의 조치 필요

### 1.4 전자상거래법 제18조 -- 청약철회의 효과 (환급 의무)

| 항목 | 규정 내용 |
|---|---|
| **환급 기한** | 청약철회를 받은 날로부터 **3영업일 이내** |
| **지연배상금** | 환급 지연 시 **연 15%** |
| **신용카드 결제** | 지체 없이 결제업자에게 **대금 청구 정지/취소 요청** 의무 |
| **결제업자 의무** | 통보 받은 날로부터 **3영업일 이내** 결제 취소 |

**NOD 현행 문제**: "5~10 영업일 이내 환불 처리"로 고지 중이나, 법률상 **3영업일 이내**. 즉시 수정 필요.

### 1.5 콘텐츠이용자보호지침 (시행 2024.3.14)

**서비스 장애 시 보상 기준:**

| 장애 유형 | 보상 기준 |
|---|---|
| 월 기준 장애 10시간 이하 | 장애 시간만큼 이용기간 무료 연장 |
| 월 기준 장애 10시간 초과 | 10시간 + 초과 시간의 2배 무료 연장 |
| 월 기준 장애 72시간 초과 | **계약 해제/해지 가능 + 잔여기간 이용료 환급 + 손해배상** |

### 1.6 소비자분쟁해결기준 (공정거래위원회 고시, 2024.12.27 개정)

- 사업자 귀책으로 서비스 이용 불가: **전액 환불**
- 계약 해지 시: 미이용 기간 **일할 계산 환불**
- 자동 갱신 구독: 갱신 전 통지 의무, 미통지 시 **갱신 이후 전액 환불 가능**

## 2. SaaS 구독 서비스 환불 정책 설계

### 2.1 월간/연간 구독 환불 기준 차이

| 구분 | 월간 구독 | 연간 구독 |
|---|---|---|
| 법정 청약철회 | 7일 이내 전액 환불 | 7일 이내 전액 환불 |
| 권장 환불 기간 | 7~14일 | 14~30일 |
| 기간 경과 후 | 잔여 기간 일할 환불 | 잔여 기간 월할/일할 환불 |
| 벤치마크 (Notion) | 3일(72시간) 전액 | 30일 전액 |

### 2.2 중도 해지 시 환불 계산 방법

**일할 계산 방식 (권장):**
```
환불금액 = 결제금액 - (결제금액 / 총 이용일수 × 실제 이용일수)
```

**월할 계산 방식 (연간 구독):**
```
환불금액 = 연간결제금액 - (월간정상가 × 이용 월수)
```

**NOD 구체적 예시 ($5/월 기준):**
- 연간 구독 $48/년($4/월), 6개월 이용 후 해지:
  - 월할: $48 - ($5 × 6) = $18 환불
  - 일할: $48 - ($48/365 × 180) = $24.33 환불

### 2.3 자동 갱신 후 환불 가능 기간

**법률 요건:**
- 자동 갱신 전 사전 통지 의무 (갱신일 전 합리적 기간 내)
- 미통지 시: 갱신 이후 **전액 환불** 의무
- 통지한 경우에도: 갱신일로부터 **7일 이내** 청약철회 가능

**권장 정책:**
- 갱신 7일 전 이메일/앱 내 알림 발송
- 갱신일로부터 7일(법적 최소) ~ 14일(권장) 이내 전액 환불
- 14일 경과 후: 잔여 기간 일할/월할 계산 환불

### 2.4 무료 체험(Trial) 유료 전환 시

- 무료 체험 종료 전 유료 전환 알림 필수 (최소 3일 전)
- 유료 전환 후 7일 이내 전액 환불 보장
- 무료 체험 기간 중 언제든 취소 가능

### 2.5 업그레이드/다운그레이드

- **업그레이드**: 잔여 기간 일할 계산 추가 과금 또는 다음 주기부터
- **다운그레이드**: 현재 기간 종료까지 기존 기능 유지, 다음 주기부터 적용

### 2.6 프로모션/할인 코드

- 프로모 코드 무료 기간: 환불 대상 아님
- 할인 코드 적용 결제: 실제 결제 금액 기준 환불
- 프로모 기간 종료 후 유료 전환: 일반 유료와 동일 환불 정책

## 3. 디지털 콘텐츠 특화 환불 이슈

### 3.1 이미 소비된 디지털 콘텐츠

- AI 분석 요약이 이미 생성된 경우 해당 건은 "소비된 콘텐츠"
- 단, 구독 기간 잔여분에 대해서는 "가분적 용역" 논리로 환불 가능

### 3.2 AI 분석 크레딧/할당량 소진 후

- 할당량 모두 소진해도 구독 취소 자체는 가능
- 환불 시 소진된 크레딧 가치 공제 고려
- 과도한 공제는 부당 약관 판단 가능

### 3.3 "만족 보장" 정책

- 광고/약관에 명시 시 법적 구속력 있는 계약 조건
- "합리적 사유 없는 반복적 환불 요청"은 권리 남용으로 거부 가능
- 구체적 조건(기간/횟수 제한 등) 명시 바람직

## 4. 결제 수단별 환불 처리

### 4.1 Paddle (NOD 현재 MoR)

- Paddle이 MoR로서 결제/세금/환불 직접 담당
- 일회성: 거래일로부터 **14일 이내** 환불 요청 가능
- 구독: 마지막 갱신일로부터 **14일 이내**
- 60일 경과 후: 환불 처리 불가
- **한국 소비자보호법은 Paddle 정책과 무관하게 NOD에 적용** → 차액은 NOD 부담 가능

### 4.2 환불 처리 기간 법적 요건

| 법률/규정 | 환불 처리 기한 |
|---|---|
| 전자상거래법 제18조 | **3영업일** |
| 전자상거래법 시행령 (결제업자) | **3영업일** |
| 지연배상금 | **연 15%** |
| Paddle 정책 | 14일 이내 요청, 60일 절대 기한 |

### 4.3 인앱 결제 (향후 모바일 앱 대비)

- **Apple**: Apple에 직접 환불 요청 (reportaproblem.apple.com)
- **Google Play**: 구매 후 48시간 이내 자동 환불, 이후 개별 심사

## 5. 분쟁 해결 절차

```
1단계: 사업자 직접 해결
   └─ 소비자 불만 접수 → 사업자 자체 해결 시도
        ↓ (미해결 시)
2단계: 소비자 상담/피해구제
   └─ 1372 소비자상담센터 상담
   └─ 지자체 소비생활센터 신고
        ↓ (미해결 시)
3단계: 한국소비자원 피해구제
   └─ 합의 권고 → 합의 성립 시 종료
        ↓ (합의 불성립 시)
4단계: 소비자분쟁조정위원회 분쟁조정
   └─ 조정결정 → 양 당사자 수락 시 재판상 화해 효력
        ↓ (불복 시)
5단계: 사법적 구제
   └─ 소액사건심판 / 민사소송
```

- **한국소비자원**: 소비자24 (consumer.go.kr) 온라인 신청, 무료
- **소액사건심판**: 3,000만 원 이하, 변호사 없이 본인 소송 가능

## 8. 환불 정책 고지 의무

### 결제 전 고지

- 결제 페이지에서 환불/청약철회 조건 **명확히 표시**
- 결제 버튼 근처에 환불 정책 링크 배치
- 결제 확인 이메일에 환불 정책 링크 포함

### 약관 포함 시 주의

- 소비자에게 불리한 조항은 약관규제법에 의해 **무효** 가능
- 법정 기준(7일)보다 불리한 조건은 무효
- **명확하고 이해하기 쉬운 언어**로 작성

### 정책 변경 시

- 변경 정책은 **시행일 이후 신규/갱신 결제**부터 적용
- 기존 결제 건은 **결제 시점 정책** 적용
- 기존 사용자에게 **사전 고지** 필요 (최소 7일 전)

## 10. 권고 환불 정책 구조안

```
1. 청약철회 (무조건 전액 환불)
   - 최초 결제일 또는 자동 갱신일로부터 7일 이내
   - EU/UK 거주 사용자: 14일 이내

2. 기간 경과 후 환불 (일할 계산)
   - 7일(또는 14일) 경과 후 ~ 결제 기간 종료 전
   - 환불금액 = 결제금액 - (결제금액 / 총일수 × 이용일수)
   - 연간 구독: 월간 정상가 기준 이용분 공제

3. 자동 갱신 환불
   - 갱신 7일 전 사전 통지
   - 갱신일로부터 7일(한국)/14일(EU) 이내 전액 환불

4. 환불 불가 사유
   - 프로모 코드로 부여된 무료 이용 기간
   - 이미 소진된 AI 분석 크레딧 (잔여 기간 환불과 별도)

5. 서비스 장애 보상
   - 월 10시간 이하: 장애 시간만큼 연장
   - 월 10시간 초과: 10시간 + 초과분 2배 연장
   - 월 72시간 초과: 해지 + 잔여기간 환불 + 손해배상

6. 환불 처리
   - 3영업일 이내 환불 절차 개시
   - 신용카드: 결제업자에 즉시 청구 취소 요청
   - 지연 시 연 15% 지연배상금

7. 분쟁 해결
   - 1차: 이메일 문의
   - 2차: 한국소비자원 (1372)
   - 3차: 소비자분쟁조정위원회
```
