# NOD 제품 배경
작성 기준: 2026-09-13. 저장소의 제품 결정 문서와 현재 화면 소스를 읽어 정리했다. 이 문서는 디자인 착수 전 배경 자료이며 디자인 생성 요청이 아니다.

## 제품과 사용 맥락
NOD는 나중에 다시 볼 웹페이지를 저장하고 찾아 여는 개인 링크 라이브러리다.
브라우저에서 읽던 페이지를 떠나지 않고 확장 프로그램 툴바 아이콘으로 저장한다. 웹앱에서는 로그인한 사용자 자신의 링크를 조회·검색·열기·삭제한다.
해결하려는 사용 과제는 관심 있는 페이지를 간단히 보관하고 다시 찾는 것이다. 특정 직군이나 연령을 타깃으로 확정한 자료는 없다.

## Phase 1 제품 계약
- 저장하는 정보: URL, 제목, 출처, 저장 시각.
- Google 로그인과 개인별 링크 보관함.
- Manifest V3 확장 프로그램으로 현재 탭을 한 번에 저장. 최초에는 계정 연결이 필요하다.
- 웹앱에서 목록, 검색, 원문 새 탭 열기, 삭제.
- 기사 본문 수집, AI 요약·분석, 주장·관계 추출은 제외한다.
- 태그, 폴더, 협업, 공유, 추천 피드, 읽음 상태 등은 현재 확정된 기능이 아니다. 기존 기능인 것처럼 설계에 넣지 않는다.

## 현재 화면과 흐름
1. 비로그인 홈: 제품 소개, Google로 시작하기, 확장 프로그램 사용 안내.
2. 로그인 후 라이브러리: 계정 정보와 로그아웃, 저장한 링크 목록, 검색, 더 보기.
3. 링크 항목: 제목, 출처 도메인, 저장 날짜, URL, 원문 열기, 삭제. 현재 삭제는 확인 후 실행한다.
4. 라이브러리 보조 영역: 확장 프로그램 연결·저장 안내, 모든 확장 프로그램 연결 해제.
5. 확장 프로그램 설정: 서비스 주소, 계정 연결 상태, 연결/현재 브라우저 연결 해제, 라이브러리 열기, 마지막 활동 상태.
6. 필요한 상태: 로그인 확인 중, 링크 로딩, 아직 저장한 링크 없음, 검색 결과 없음, 조회 실패와 재시도, 삭제 성공/실패, 연결 해제 진행/성공/실패, 세션 만료.
현재 웹앱은 한국어, 확장 설정 화면은 영어다. 제품 전체 언어 정책은 아직 별도로 결정되지 않았다.

## 이번 디자인 작업의 맥락
사용자는 다음 작업을 UX/UI, 화면 설계, 시각 디자인, 디자인 시스템 설계로 정했다. Open Design에서 디자인 시스템부터 수립한 뒤 화면 작업을 이어갈 예정이다.
색상, 서체, 로고, 컴포넌트 형태, 레이아웃은 아직 확정되지 않았다. 현재 화면의 스타일을 확정된 브랜드 가이드로 취급하지 않는다.
디자인 시스템은 위 제품과 실제 상태를 지원하는 데 필요한 범위부터 잡는다. 색상·타이포그래피·간격·버튼·입력·링크 항목·피드백 상태 등은 향후 설계 검토 대상이며 이 문서에서 확정하지 않는다.
NOD 디자인 생성 모델에 대한 사용자 지정은 **Astra 6 medium (gpt-6-astra, reasoning: medium) 고정**이다. 생성 실행 때 지원 여부와 정확한 모델 식별자를 확인하고 명시한다. 사용할 수 없으면 임의로 다른 모델로 대체하지 않는다. 이 기록 자체가 앱의 모델 설정을 변경한 것은 아니다.

## 구현과 검증 상태
활성 제품 코드는 apps/nod 하나다. Cloudflare Worker + D1, vanilla HTML/CSS/JavaScript 웹앱, Manifest V3 확장 프로그램으로 구성한다.
HTML 구조, CSS 스타일, JavaScript 동작을 분리한다. 디자인 결정에 필요한 만큼만 구조를 도입하고, UI 프레임워크 도입을 전제로 설계하지 않는다.
handoff 문서에는 로컬 Google 로그인, 설치된 확장 프로그램 연결, 툴바 저장, 중복 처리, 검색을 Aside(Chromium)에서 확인한 기록이 있다. 이번 배경 정리에서 이 동작을 재검증한 것은 아니다.
문서 기준 원격 배포와 DNS 작업은 미완료다. 공개 출시 또는 Chrome Web Store 배포 완료를 주장하지 않는다.
