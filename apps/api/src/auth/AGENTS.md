# AGENTS.md - Authentication Service Guidance

This document provides guidance for AI agents operating within the `apps/api/src/auth/` directory.

## 1. Context

The `apps/api/src/auth/` directory contains the logic for user authentication and authorization within the API.

## 2. Specific Guidance

- **Authentication**: Focus on JWT/OAuth2 implementation.
- **Authorization**: Implement RBAC and scopes.
- **Security**: Handle password hashing and input sanitization.
