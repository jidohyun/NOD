# NOD 로고

Figma의 N 모노그램과 노란 체크 벡터 원본에서 내보낸 로고 12종이다. 생성 이미지 시안과는 별개의 자산이다.

- `light/`: 밝은 배경용 검은 심볼·글자
- `dark/`: 어두운 배경용 밝은 심볼·글자
- 각 모드 안에 `square/`(심볼), `horizontal/`(심볼과 NOD 글자)
- 각 형태 안에 `nod-logo-small`, `nod-logo-medium`, `nod-logo-large`
- `.svg`: 투명 배경, 글자 윤곽선 처리. 웹에서 우선 사용한다.
- `@2x.png`: 투명 배경, 표시 크기의 2배 해상도

| 형태 | 소 표시 크기 | 중 표시 크기 | 대 표시 크기 |
| --- | --- | --- | --- |
| 정사각형 | 128×128 | 256×256 | 512×512 |
| 가로형 | 240×60 | 480×120 | 960×240 |

웹 경로 예시: `/assets/logos/light/horizontal/nod-logo-medium.svg`.
이미지의 비율을 유지하고, PNG는 파일명에 표시한 2배 해상도를 고려해 표시 크기를 지정한다.
