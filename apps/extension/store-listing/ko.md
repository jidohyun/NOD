# NOD Chrome 확장 프로그램

웹의 글을 저장하고 AI로 요약해 나중에 다시 찾게 해주는 Chrome 확장 프로그램입니다.

## 개요

NOD는 읽고 지나치기 쉬운 웹 콘텐츠를 한곳에 모으고, AI로 핵심만 빠르게 파악할 수 있게 도와줍니다.  
읽고 있는 글을 저장하면 대시보드에서 요약, 핵심 포인트, 다시 찾아볼 근거를 함께 관리할 수 있습니다.

## 사용 방법

1. 읽고 있는 웹페이지에서 NOD 확장 프로그램을 엽니다.
2. 저장과 요약을 한 번에 실행합니다.
3. NOD 대시보드에서 요약된 내용을 다시 읽고 필요한 글을 찾아봅니다.

## 핵심 기능

- **원클릭 저장**: 읽고 있는 웹 콘텐츠를 바로 저장합니다.
- **AI 요약**: 긴 글의 핵심 내용을 빠르게 파악할 수 있습니다.
- **나중에 다시 찾기**: 저장한 콘텐츠를 정리해 두고 필요할 때 다시 참고할 수 있습니다.
- **대시보드 연동**: 저장한 콘텐츠를 NOD 대시보드에서 이어서 확인합니다.

## 안내

- 이 확장 프로그램은 사용자가 직접 저장한 웹 콘텐츠를 기준으로 동작합니다.
- AI 요약은 참고용이며, 원문 확인이 필요한 중요한 판단을 대신하지 않습니다.
